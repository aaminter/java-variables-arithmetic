# Java Variables and Arithmetic Operations

![Java CI](https://github.com/aaminter/dz4/actions/workflows/ci.yml/badge.svg)

Учебные упражнения по базовым конструкциям Java.

## Темы
- объявление переменных и вывод значений;
- примитивные типы и числовые операции;
- арифметические выражения;
- вычисление сумм и разниц на простых примерах.

## Запуск
Требуется JDK. Откройте проект в IntelliJ IDEA и запустите класс `Main`.

## Статус
Небольшая учебная работа по основам языка, не самостоятельное прикладное приложение.
